The question

Each scan contains three monochrome exposures in vertical order B · G · R. The camera moved slightly between exposures, so simply stacking the thirds creates colored ghosts. The goal is a single RGB photograph with a fast translation model, while keeping every choice fixed across the dataset.

vertical plate
B / G / R→split + normalize→pyramid search→crop + color→final RGB

Method

01

Translation search

The blue plate is the reference. Green and red are translated by integer (dy, dx) offsets. At every candidate, the score is computed only on the true overlap (never circular wrap-around).

score = 0.70 · NCC(intensity) + 0.30 · NCC(edge magnitude)
02

FFT phase initialization

For the large TIFFs, a Hann-windowed FFT cross-power spectrum estimates the global shift on a 4× edge-map thumbnail. The phase peak is robust to different filter brightness and avoids the false coarse-level peak that previously misregistered Emir and self portrait.

03

Local registration

The phase estimate is refined in a small full-resolution window with overlap-aware NCC plus edge agreement. JPEGs use the same routine at native scale, while the required exhaustive single-scale NCC baseline is also retained for comparison.

04

Photographic cleanup

After alignment, the valid overlap is intersected across channels. Border rows/columns are then removed only when they are clipped black/white or cross-channel outliers. Finally, 1–99% percentile contrast, restrained gray-world gains, and a mild gamma curve make the negative look photographic.

Bells & whistles

Automatic crop

Keep only photographic content

The crop starts with the mathematically valid intersection implied by the offsets, then scans inward for clipped black/white, low-information, and high-disagreement border runs. It is data dependent rather than a fixed margin.

Automatic contrast

Recover usable dynamic range

Robust 1st/99th percentiles avoid one dust speck controlling the stretch. A gray-world gain is clipped to ±18%, so color balance improves without turning warm scenes gray.

Better features

Intensity + edge agreement

Central differences provide a tiny, fast edge detector. Combining it with mean-subtracted NCC handles the filter-dependent exposure changes in the historical negatives.

Reproducibility

One parameter set

No image-specific offsets or hand-tuned crops are used. The submission implementation is in code/main.py; the recorded measurements are in results.json.

Failure analysis. A translation is a deliberately limited model. If a plate has local warping, strong saturation, or a large blank border, one global offset cannot make every object agree. Emir is the stress test: its filter brightness differs strongly, so the final R score is lower than the architecture examples; the wider coarse window recovers a visually coherent offset without a hand correction. The reported NCC values make every case auditable.

Takeaways

Scale matters

Searching large TIFFs at native resolution is wasteful. The pyramid preserves the correct basin while making each local search small.

Metrics matter

NCC removes per-channel mean and scale; gradients add a feature whose peaks survive brightness differences.

Presentation matters

Alignment, crop, contrast, and white balance are separate stages. Keeping them separate makes both the code and the visual result easy to audit.
